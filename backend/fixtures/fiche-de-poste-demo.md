# Développeur·se Python confirmé·e — Atelier Nova

*Document fictif, inventé pour la démonstration.*

**Atelier Nova** est une PME de 80 personnes basée à Nantes qui édite une plateforme SaaS de gestion de planning pour les ateliers de réparation (vélos, électroménager, horlogerie). Notre équipe produit compte 14 personnes, dont 7 développeurs.

## Le poste

CDI, temps plein, hybride (2 jours sur site). Rattaché·e au responsable technique.

Vous rejoignez l'équipe « Planning » qui maintient le cœur métier de l'application (API, calcul de créneaux, facturation).

## Missions

- Concevoir et développer de nouvelles fonctionnalités en Python (Django pour le back-office, FastAPI pour l'API publique).
- Écrire des requêtes SQL efficaces sur PostgreSQL et faire évoluer le schéma (migrations).
- Écrire et maintenir des tests automatisés (pytest) ; viser une couverture utile, pas un chiffre.
- Participer à la chaîne d'intégration continue (GitLab CI) et au déploiement en conteneurs Docker.
- Faire des revues de code et accompagner deux développeurs juniors (mentorat, binômage).
- Lire et rédiger de la documentation technique en anglais.

## Profil recherché

- Au moins 4 ans d'expérience en développement Python en production.
- Maîtrise d'un framework web Python (Django ou FastAPI).
- Bonne pratique de SQL et d'une base relationnelle (PostgreSQL de préférence).
- Habitude des tests automatisés et de l'intégration continue.
- Connaissance de Docker ; Kubernetes est un plus, pas une exigence.
- Anglais technique écrit (documentation, tickets).
- Goût pour la transmission : expérience de mentorat ou d'encadrement technique appréciée.

## Ce que nous offrons

Salaire 48–56 k€ selon expérience, 2 jours de télétravail, budget formation annuel, matériel au choix.

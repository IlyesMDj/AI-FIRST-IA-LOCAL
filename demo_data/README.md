# Synthetic demo CVs

All people, contact details and employers in these files are fictitious.
They are generated by `backend/app/demo/synthetic.py`. Use them to try the import (PDF, scanned PDF, DOCX, TXT).
`nora_fr_fullstack_injection.pdf` contains a deliberate prompt-injection attempt; `camille_fr_backend.pdf` contains deliberately sensitive data (birth date, family status, address) to demonstrate redaction.
